# OEM Backups

This folder contains verified original prompt containers used for device
recovery when the manufacturer download is unavailable.

Files are grouped by supported device model:

- `JBL Tune 720BT/English_prompt_v0.0.5.bin`

Do not modify these files. Tone Slapper verifies the expected file size,
SHA-256 hash, and container structure before allowing recovery use.

This is the repository backup location. When the portable application
downloads a verified OEM file, its runtime copy is saved directly beside the
EXE for easy portable use.
