# JBL Tune 720BT Custom Sound Pack

Ready-to-upload custom prompt container for BT Tone Slapper.

## Compatibility

- Target device: JBL Tune 720BT
- PID: `20b4`
- Other device models have not been verified

## Customized prompts

- Power on
- Power off
- Connected
- Pairing
- Battery is low
- Maximum volume

All remaining prompts use the OEM English sounds.

## Use

Open `JBL_prompts_custom.bin` with **Open existing**, select a supported device,
and use **Upload**. Keep the headphones powered on and connected until the
upload completes.
